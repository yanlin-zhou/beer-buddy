# 服务速查：先确认，再给一个动作

需要处理温度、倒酒、新鲜度、储存或采购数量时读对应段。照片能读标签、看颜色和泡沫，不能单独诊断酒坏、杯脏、酒线脏。用户没有报告异常时，不主动做故障清单。

## 温度与杯子

- 酒厂服务建议优先。没有说明时，先冷藏；觉得香气弱或太冰，可放一会再闻尝，不保证“几分钟到几度”。室温、容器、杯量和起始酒温都会影响回温。
- 不按颜色升温，也不把 13°C 当通用上限：Weihenstephan 深色小麦建议 6–8°C，Cantillon Gueuze 建议 15°C。这些只适用于对应产品，核验于 2026-10-14。[Weihenstephan](https://www.weihenstephaner.de/en/our-beers/dark-wheat-beer-1)、[Cantillon](https://www.cantillon.be/gueuze-en?lang=en)
- 干净的普通玻璃杯就够用；小杯方便比较，不必先买专用杯。倒杯后更方便闻香。[Cicerone 在家服务](https://www.cicerone.org/us-en/blog/the-cicerone-guide-to-drinking-beer-at-home)
- 杯子应无油脂、洗涤剂等残留。清水成膜、挂杯是检查线索；局部粘泡可能提示残留，不能只凭照片认定是油或宣布卫生合格。避免结冰的杯子，冰层可能让二氧化碳迅速逸出。[Cicerone 清洁](https://www.cicerone.org/us-en/blog/cleaning-glassware)、[BA 手册印刷页 55](https://cdn.brewersassociation.org/wp-content/uploads/2019/03/13094643/Draught-Beer-Quality-Manual-2019.pdf#page=67)

## 倒酒

普通瓶罐可先倾杯倒入，再逐渐立直，让适量泡沫形成；泡沫太多就降低倒速。杯型、酒温和酒款不同，不把“两指”当合格线，也不承诺这样就不胀气。生啤服务细节见 [BA 手册印刷页 56–57](https://cdn.brewersassociation.org/wp-content/uploads/2019/03/13094643/Draught-Beer-Quality-Manual-2019.pdf#page=68)。

- 酵母沉淀是否倒入，先按酒厂说明；不统一把所有小麦摇匀，也不统一排除所有比利时酒的沉淀。
- 氮气罐按包装说明操作。Guinness Draught 官方同时列倾杯倒与 hard pour；带 widget 不代表只有一种正确倒法，Nitrosurge 等另有要求。[Guinness 在家倒酒](https://www.guinness.com/en-gb/experiences/guinness-at-home)
- 泡沫少先确认这款的正常表现。若喝着也没气，可请店员检查或换杯；不直接说“倒坏了”。杯子、酒温、碳酸水平、出酒系统、酒本身及放置时间都可能参与。[BA 手册故障排查，印刷页 81](https://cdn.brewersassociation.org/wp-content/uploads/2019/03/13094643/Draught-Beer-Quality-Manual-2019.pdf#page=93)

## 日期、新鲜度与储存

1. **先认日期类型。** 灌装日、建议饮用期、接桶日不同；看清年份和日月顺序。酒单的罐装日期不能默认对应当前桶；新接桶也不等于新酿。需要问时说：“这款是哪批的，一直冷藏吗？”[Cicerone 考纲：日期与包装](https://www.cicerone.org/sites/default/files/resources/US_English_CC_Syllabus_V5.0.pdf)
2. **再看保存。** IPA、淡色艾尔优先冷藏、灌装较近且在酒厂建议期内的产品。九十天可作个人采购偏好，不能叫统一保质期；所有深色和烈性酒也要看日期。[Sierra Nevada 日期说明](https://sierranevada.com/blog/our-beer/does-beer-expire)
3. **放久不作保证。** 一年前的 IPA 往往风味已衰减，但不能保证“不会坏”或“香气全没了”。包装受损、状态异常或保存不明时先核对，不用做菜兜底。陈年只选酒厂明确适合的产品。[Sierra Nevada 保存与异常](https://sierranevada.com/blog/our-beer/does-beer-expire)、[Cicerone 陈年边界](https://www.cicerone.org/us-en/blog/the-cicerone-guide-to-drinking-beer-at-home)
4. **冷藏、避光，运输也保冷。** 罐装能遮光，不能保证未受热或仍然新鲜；棕瓶也应避光。光可形成典型臭鼬味，热会加快老化，不把冷热变化直接称为“臭鼬化”。陈年产品另按酒厂说明储存。[Sierra Nevada 储存](https://sierranevada.com/blog/our-beer/does-beer-expire)

## 用户说味道不对时

先复述感受，再核对酒名、风格与产品说明。只需给一个下一步：“这味道挺明显，请店员确认一下是不是这款正常状态。”用户不愿继续尝，不要求再喝一口来证明。

| 用户描述 | 能提出的线索 | 不能直接下的结论 |
|---|---|---|
| 湿纸板、风味变钝 | 可能氧化，核对日期与保存 | 单凭味道锁定哪段运输或库存出错 |
| 黄油、奶油糖 | 可能是双乙酰；部分风格允许低量 | 酒线脏、多款如此就该换店 |
| 意外的酸味、醋味 | 先看这款是否本就有酸味，再请店员复核 | 凭照片或一个词宣布感染 |
| 消毒水、塑料等异味 | 先请店员检查并处理 | 确定是杯子消毒剂残留 |

依据：[BJCP Beer Characteristics：氧化、双乙酰、酸味及酚类](https://www.bjcp.org/exam-certification/program/studying/beer-exam-study-guide/troubleshooting/)。这些是可能原因，不是远程检测结果。

仅被问到维护时补充：BA 手册建议酒线至少每 14 天清洗一次，具体还须遵守当地要求和设备维护方案；这是维护建议，不是全球统一法律，也不能用味道倒推出上次清洗日。[BA 手册印刷页 77 清洗摘要](https://cdn.brewersassociation.org/wp-content/uploads/2019/03/13094643/Draught-Beer-Quality-Manual-2019.pdf#page=89)

## 标签数字与采购数量

- `ABV`／`%vol` 是酒精体积分数；标作“原麦汁浓度 11°P”的数字不是 11% 酒精度，也不能固定换算成 4% 或 5%。看字段名，不只看一个“度”字。[BA 旗下 CraftBeer.com：ABV](https://www.craftbeer.com/beer/beer-styles-guide)、[麦汁比重与发酵](https://www.craftbeer.com/craft-beer-muses/defining-gravity)
- 采购先按**实际愿意参与的人数 × 每人计划分杯量 × 轮数**算该款总容量，再除以单瓶／罐容量并向上取整。容量未知就标明假设；“每人两罐”不是默认饮用安排。预算不足可减款数或分杯量。
- 算术示例：8 人各取某款 100 ml，共需 800 ml。可用 `3 × 330 ml = 990 ml`、`3 × 355 ml = 1065 ml`、`2 × 473 ml = 946 ml` 或 `2 × 500 ml = 1000 ml`；两罐 330／355 ml 不够。这里未单独预留倒洒损耗，实际可少倒，余量不用喝完。
- 不喝的人单独准备饮品，不计入酒精分杯人数；还要驾驶时停止含酒精推荐。若已经饮酒，安排代驾或其他返程方式，不计算“等多久能开”。
- 收尾只记录用户确实提供的信息，默认水或用户明确选择的无酒精饮品；不因空杯、记账或“结束了”追加含酒精的最后一杯。
