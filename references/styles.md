# 风格速查：按当下想喝的味道找

只在需要选酒或解释风格时读。以下是常见预期，不是具体酒款的保证；**产品 ABV、配料、价格都看标签或对应官方页面**，不拿风格区间填酒单空白。点过什么只是线索，没有新手到老手、淡到烈的升级路线。

## 先匹配偏好

- 想清爽、少苦：先看已确认低苦的 Helles、Kölsch、Blonde Ale；皮尔森可能明显苦，不能一概替代。
- 不接受苦味：先核对具体低苦款；想试德式小麦，还要确认对香蕉／丁香香不排斥。Hazy、Session、果味都不保证低苦。
- 不爱苦不等于喜欢酸；用户没有表达想喝酸时，不把酸啤当默认补位。
- 想换口味：只换一个用户愿意换的维度，例如仍要清爽，试一点烘烤香；保持原来的选择也完全成立。
- 不喝或还要驾驶：停止含酒精推荐，可选水或已确认适合其需求的无酒精饮品。“清淡、低度、Session”都不等于无酒精。

## 清爽与麦香

| 风格 | 常见预期 | 选的时候留意 |
|---|---|---|
| 德式皮尔森 German Pils | 干爽，草本或花香，苦感较清楚 | 皮尔森有多种地区版本；不能说“和淡拉格一样不苦” |
| 慕尼黑淡色 Helles | 面包、谷物麦香，苦味较克制 | 有苦味，不保证人人觉得柔和 |
| 科隆 Kölsch | 轻盈，细微果香，收口干 | 上发酵后冷贮，不用“艾尔一定浓”解释它 |
| 金色艾尔 Blonde Ale | 温和麦香，常有轻微果香 | 酒花表现会变；与比利时 Blond 区分 |
| 黑拉格 Schwarzbier | 烘烤香较克制，收口相对干爽 | 黑色不能推出低度、不苦或像可乐 |

依据：[BJCP 5B、5D](https://www.bjcp.org/style/2021/5/)、[4A Helles](https://www.bjcp.org/style/2021/4/)、[18A Blonde Ale](https://www.bjcp.org/style/2021/18/18A/blonde-ale/)、[8B Schwarzbier](https://www.bjcp.org/style/2021/8/)。

## 果香、香料与酸味

| 风格 | 常见预期 | 选的时候留意 |
|---|---|---|
| 德式小麦 Weissbier／Hefeweizen | 香蕉、丁香香，较充足的气泡 | 香气常来自发酵；具体有无加料看配料 |
| 比利时白啤 Witbier | 柑橘、香料香，苦味通常较低 | 常用橙皮和芫荽，不能对未知酒款保证配方 |
| 赛松 Saison | 收口干，常见胡椒或果香，气泡足 | 不一定酸，也不能只凭“农场”猜 ABV |
| 柏林白 Berliner Weisse | 乳酸感，轻盈，低苦 | 确认用户接受酸味 |
| 古斯 Gose | 酸、轻微咸感，可能有芫荽香 | 不要求咸味突出；加水果的版本另看描述 |
| 水果酸啤 Fruited Sour | 水果与酸味的组合 | 大类很宽，酸甜、酒体、ABV 都需看具体款 |
| 兰比克／格兹 Lambic／Gueuze | 发酵与陈酿带来的酸香 | 气泡、果味、甜度各不相同；格兹常混合不同年份兰比克 |

依据：[BJCP 10A](https://www.bjcp.org/style/2021/10/)、[24A Witbier](https://styles.bjcp.org/bjcp-2021-beer/24/24a-witbier)、[25B Saison](https://www.bjcp.org/style/2021/25/)、[23A、23D–G 酸啤](https://www.bjcp.org/style/2021/23/)。

## 酒花香与苦味

| 风格或酒单名称 | 常见预期 | 选的时候留意 |
|---|---|---|
| 美式淡色艾尔 American Pale Ale | 酒花香清楚，麦芽有支撑 | 常比 IPA 温和，但不存在固定“苦一半” |
| 美式／西海岸 IPA | 常见柑橘、松针或其他酒花香，苦感较明确 | 西海岸是酒单常用描述；不能保证都清澈或苦味立刻散去 |
| 浑浊 IPA Hazy／NEIPA | 强果香，口感较柔，浑浊 | 感知苦度可从低到中高；不作为零苦偏好的默认答案 |
| Session IPA | 通常强调较低酒精度下的酒花表现 | 与谁相比、低到多少都看标签；仍可能很苦 |
| 双倍 IPA Double IPA | 强酒花表现，通常酒精度也较高 | 不说“一杯顶两杯”；小杯只是可选份量 |

依据：[BJCP 18B](https://www.bjcp.org/style/2021/18/18B/)、[21A–C IPA](https://www.bjcp.org/style/2021/21/ipa/)、[22A Double IPA](https://www.bjcp.org/style/2021/22/)。

## 烘烤与浓郁麦芽

| 风格 | 常见预期 | 选的时候留意 |
|---|---|---|
| 爱尔兰世涛 Irish Stout | 烘烤、咖啡方向，收口偏干 | 不一定用氮气；Guinness 的不同产品不能混为一款 |
| 波特 Porter | 常见巧克力、面包皮或烘烤香 | 英式、美式、波罗的海波特差异大，不保证比世涛柔 |
| 燕麦世涛 Oatmeal Stout | 烘烤香，燕麦可带来较滑的口感 | 甜度因款而异；燕麦不等于乳糖 |
| 牛奶／甜世涛 Milk／Sweet Stout | 烘烤与残留甜味，常用乳糖 | 对具体乳成分需求，核对配料和产品说明 |
| 帝国世涛 Imperial Stout | 浓郁烘烤、麦芽与酒精表现 | 甜苦差异大；不自动安排为“最后一杯” |
| 三料 Tripel | 金黄色，果香、香料香，较干 | 颜色浅不等于度数低 |
| 比利时烈性深色／四料 | 常见深色水果、麦芽香 | 名字不证明有修道院认证 |
| 博克／双料博克 Bock／Doppelbock | 麦芽、面包或烘烤面包香 | 强度、颜色有差别，不共用一个 ABV |
| 大麦酒 Barleywine | 浓郁麦芽、果香，美式版本也可突出酒花 | 能否陈年按具体酒款与酒厂说明 |

依据：[BJCP 15B Irish Stout](https://www.bjcp.org/style/2021/15/)、[16A–B](https://www.bjcp.org/style/2021/16/)、[20 美式波特与世涛](https://www.bjcp.org/style/2021/20/)、[26C–D](https://www.bjcp.org/style/2021/26/)、[9A Doppelbock](https://www.bjcp.org/style/2021/9/)、[22C American Barleywine](https://www.bjcp.org/style/2021/22/)。

## 真正落到酒单上

先选符合用户偏好的现有酒款，再处理新鲜度、杯量和价格；不因为“更新”就推荐一个用户明确不喜欢的风格。酒名陌生时读风格和产品描述，没有就问店员。

Flight 是用户想比较时的选择，不与每人一杯叠加成默认订单。若按风味安排，让较细微的在前、强酸／强苦／强烘烤靠后，具体款可调整并留水清口；若标注“按 ABV”，必须使用已知产品数字实际排序。未知 ABV 不猜，颜色也不是排序尺。
