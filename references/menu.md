# 酒单怎么挑：几款，各有一个理由

用于清楚酒单照片、泛问“看看有什么”或明确要多角度推荐。先筛用户已知的限制，再选理由。单杯介绍、指定故事和明确只选一款走原任务。

## 便携版核心

<!-- STARTER:BEGIN -->
清楚的酒单照片或“帮我看看这张单”，默认给 3–5 个不同酒款的候选，通常 3 或 4 个即可。每项用“选择角度＋菜单编号／原名＋一两句具体理由”，不要先问偏好表或抄整张酒单。角度从有故事、特殊原料／工艺、当季机会、口味方向、预算份量、已知食物搭配等选，按证据选几项，不机械凑全。没有偏好时说“想……可以看……”；同款不重复占位，只有两款可靠就给两款。用户明确只要一款、只听某个故事、已选定一杯或结束时，完成那个任务。

故事项当场给可转述的真实内容，并区分产品来历、酒厂经历、风格相关的地方习俗。时令／限定需菜单或官方依据；常规供应窗口不证明本店今天在售、刚酿或即将售罄。菜单有旧年份就保留，必要时把这项标为“先核对批次”。限定、贵、度数高不等于人人必喝；口味和饮用限制优先。价格对应杯量未确认，不宣布单位量最划算；“有32oz crowler外带”不证明各行标价就是32oz。

这些是备选，不自动组成多杯订单。每项一个入选理由，有帮助时才加一个观察，不把历史、杯型、温度、风味表全配齐。不喝、喝够或要驾驶时，可以给几个聊天角度，不给尝饮动作或酒精推荐。

可用的有据例子（只有当前菜单包含对应酒款／风格时才用）：Kölsch 可以连到科隆酒馆在杯垫划杠记杯数、最后数杠结账的习俗；说这是科隆风格相关的话题，不能当成别家酒厂历史或本店服务。依据：https://gaffel.de/en/beverages/koelsch/ 。Sierra Nevada 目前把 Celebration IPA 列为10–12月的季节产品，与酒花收成有关；若菜单写2021，不能当作今年新鲜批次。依据：https://sierranevada.com/brews/celebration-ipa 。两项核验于2026-10-14；官网供应安排不是当地实时库存。烟熏辣椒等配料可直接用清楚菜单上的描述，不推断辣度或用户已尝到的味道。

## 选角度，不填栏目

| 用户可能感兴趣的理由 | 怎么选 | 怎样说到有用 |
| --- | --- | --- |
| 有故事可讲 | 与菜单实际酒款、品牌或风格有关，且有可靠出处 | 直接交付一两句经过；不只写“历史悠久、有故事” |
| 猎奇／换个体验 | 菜单写出的特殊原料、工艺，或与用户平常选择的已知区别 | 说明新意；可以留意什么，留给用户判断，不保证喜欢或“绝没喝过” |
| 当季／在这里值得留意 | 有明确供应窗口、当前菜单标记或当地关联证据 | 说清为何此时此地值得考虑；批次、货源不明时待核实，不制造错过焦虑 |
| 口味更贴近／认识一种风格 | 用户给过偏好，或菜单足以提供一个条件入口 | “想清爽、愿意有些苦感，可以看这款皮尔森”；不写绝不踩雷 |
| 预算／份量／搭配 | 价格、容量、预算或桌上食物确实已知 | 说明可比条件；不知道杯量就不算每毫升，未知食物不补写 |
| 本地／经典路线 | 产地、常年代表款或工艺有据，且与当前兴趣有关 | 说明具体关联；不把名字、名气、奖项或稀有度当品质担保 |

默认让条目方便扫描，正文约 250–400 个汉字只是编辑参考。用户要三款就三款，要详细比较再展开。不同角度可以共用来源，但不能只是给同一款酒换四个标题。所有款都相近或只有名字时，坦白区分依据不足；不按名字编“果香／限定／创始人故事”。

## 已核验的示例关联

- **Kölsch → 杯垫账单。** Gaffel 对科隆酒馆习俗的说明支持杯垫划线记杯数。Del Cielo 的某款在菜单标为 Kölsch 时，可借这个风格讲科隆生活；不能说这款来自科隆、这家酒吧也自动续杯或同样记账。完整故事见 [stories.md](stories.md#koelsch-coaster-tab)。
- **Celebration → 收成季。** 官方当前产品页列10–12月，不能覆盖照片里旧年份对应的状态。该厂区分 fresh 与 wet hops；其 fresh hops 可先烘干再较快使用，不把 Celebration 描述成“未干燥的湿酒花直接入锅”。[产品](https://sierranevada.com/brews/celebration-ipa) · [酒厂的术语解释](https://sierranevada.com/blog/our-beer/your-harvest-guide-wet-hops-and-fresh-hops)。
- **Reality Czeck → 皮尔森入口。** Moonlight 官网把它描述为柔和、干净，并提到面包与花香。这是酒厂描述，不等于用户已经喝到，也不保证不苦。官网当前4.9%与示例菜单4.8%不同，读图时保留“菜单标4.8%”；不自行判印错或改配方。[Moonlight](https://moonlightbrewing.com/products/reality-czeck)。
- **Sid's Serrano Ale → 烟熏辣椒。** 原料、ABV、价格按可见菜单；Taplands 的2023年活动页仅另证它是自家酿造，不证明当前配方、辣度或库存，不补写 Sid 身份。[Taplands 历史活动](https://www.taplands.com/events/2023/2/11/7th-annual-wake-amp-breakfast)。

以上核验日期均为2026-10-14，品牌资料仍属品牌自述。临场有合适的随包材料就用；需要确认新的限定、批次或品牌来历时才按宿主能力查证。无法查证的角度可以换掉，不要求用户等全部酒款调研完才获得选择。
