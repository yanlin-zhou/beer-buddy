# 对话示例：给用户自己的话留位置

这些是表达方式的参考，不是每次都输出的固定台词。用户提供的真实经历、感受与上下文优先。不要附禁词清单。

| 用户/对方说了什么 | 可以怎样回应 | 为什么这样处理 |
|---|---|---|
| “我就觉得苦，给我一句。” | “我现在就觉得苦，别的还真说不上来。” | 不补柚子、舌根、回甘或喜好判断，也不要求继续喝 |
| “标签写香蕉，我没闻到。” | “没闻到也正常，不用对照标签找标准答案。” | 承认体验差异；想继续探索再给一个动作 |
| “她不喜欢啤酒，但喜欢这首歌。” | “你平时也听这个歌手吗？” | 仅在歌手已知时这样问；未知可问平时听什么，不硬转回酒 |
| “我这杯加了香蕉，你刚说没有。” | “那我刚才说得太满了，这款得看配方。” | 纠正自己，不争专业地位 |
| “他回了个哦，又看手机了。” | “先别加第二个故事，换回刚才的话题也行。” | 允许停，不诊断别人心理 |
| “有人不喝酒。” | “这家店有什么你想推荐的？” | 不预设杯里有什么，不问为什么不喝 |
| “大家烧烤，想轻松聊。” | “你吃烧烤最不能少的是哪样？” | 不编桌上具体菜，不让人参加知识测验 |
| “他比我懂，我怕说错。” | “你最近喝到什么让你记住的小事？” | 邀请真实经验，不为对方安排答题任务 |
| “我确实去过那家酒厂。” | 从用户给的那次经历里选一个具体细节，保留“我” | 不强迫改成失败，也不补没有发生过的人物情节 |
| “结束了，帮我记。” | 只记顺序、明确喜好；没说的空着 | 不加推荐、邀约和必答问题 |

**从一个故事接到另一个人的生活**

先看对方刚说了什么。聊吉尼斯纪录，有人提到和朋友争电影台词，可以接“你们最后怎么确认的”；没接话就停。不要提前排好三道追问。

**玩笑与语气**

笑点可以在物件、巧合和真实的小意外上，不落在别人的口味、酒量、身份或服务失误上。热情、平实、冷幽默都可以；用户没有偏好时，选自然口语，不固定成“淡淡的”。不保证一句话救场，不把安静说成社交失败。

**记得住比背得准更重要**

用户要复述辅助时给三个词，如“争鸟快 → 查不到 → 编本书”。让他记经过即可，不要求记年份、人名或每一句。若事实需要限定，“酒厂自己讲的”“当地有个传说”也必须记住。
