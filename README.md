# 啤酒搭子 🍻

**从眼前这杯酒，找一件能顺口讲给朋友听的小事。**

不必先懂精酿。喝青岛、点 IPA、陪朋友坐一会儿，都可以用。我们希望你看完就能放下手机，用自己的话讲；朋友接起别的话题，也很好。

> **你：** 桌上是健力士，给我一个能讲半分钟的小故事。
>
> **啤酒搭子：** 吉尼斯官方讲过这个来历：健力士的一位负责人去打猎，跟朋友争欧洲哪种猎鸟飞得最快，翻书也找不到答案。后来他想到，酒馆里肯定也有这种争论，就请人编了本查纪录的书。
>
> 依据：[Guinness World Records 官方起源介绍](https://www.guinnessworldrecords.com/about-us/our-story)。这是品牌相关机构对自身起源的回顾。

怕记不住，再让它给三个词：**打猎 → 争鸟 → 编书**。记住事情的经过就行，不用背原句。

## 现在就试

**[打开「先聊一句」，复制给你的 AI →](START.md)**

不用安装，轻量版带 3 条有来源的素材。先发这段指令，再发一句自己的场景。它不是独立 App，需要你正在使用的 AI 对话工具。

想长期用，有两种完整入口：

- **普通 AI 对话：** [下载完整 PROMPT.md](https://github.com/yanlin-zhou/beer-buddy/releases/latest/download/PROMPT.md)，上传后说“请按文件中的啤酒搭子帮我”。也可[在线查看](PROMPT.md)。
- **使用 Skills 的用户：** [下载 v1.0.0 安装包](https://github.com/yanlin-zhou/beer-buddy/releases/download/v1.0.0/beer-buddy-1.0.0.zip)，按 [Claude / Codex 安装说明](docs/INSTALL.md)使用。

## 不知道说什么，就这样开口

| 此刻 | 复制这一句 |
| --- | --- |
| 烧烤摊喝青岛 | 大家喝青岛，来点能聊的地方小事，别把我们往精酿带。 |
| 酒来了，想讲个故事 | 这是福佳白啤，给我一个不用懂酒也听得明白的故事。 |
| 朋友问怎么样 | 我只觉得苦，帮我说一句，别替我编别的味道。 |
| 不喝酒也一起坐着 | 有人不喝酒，找个大家都能参与的话题。 |
| 对方聊起音乐 | 她更喜欢这家店的音乐，帮我自然接一句。 |
| 赶着点单 | 我平时喝百威，只在皮尔森和双倍 IPA 里选一个，快一点。 |
| 今天结束了 | 帮我记录：今天喝的这款我觉得苦。不要再推荐下一杯。 |

可以随时说“太长了”“换个路数”“这不像我平时说话”。对方没接，不必用更厉害的知识补救；停一下也可以。

## 里面有什么

**12 条带来源的故事与趣闻。** 有拎着回家的青岛散啤、杯垫上的账单、送奶工重新酿起的白啤，也有瓶标上衔戒指的鱼。人物、地方、食物和包装，都能成为话头。故事、观察和传说分别标注，品牌自述会保留“酒厂讲过”的说法。

还有选酒、看标签、采购容量、回应朋友和记录的参考资料。支持文字；宿主能读图时，也可以发酒单或酒标。看不清就承认，不凭酒的颜色猜度数，更不会替你说“我闻到了什么”。

专业资料以啤酒为主。在葡萄酒、白酒等聚会里也能帮你接话，但目前没有这些酒类的专业故事库。不会为了聊天要求任何人喝酒。

## 我们怎么判断它好不好

最重要的两个问题：**你能否放下手机，用自己的话讲？身边的人是否愿意接着聊？**

v1.0.0 已做多 Agent 审查、文本行为检查和发布包检查。[查看验证记录及尚未验证的部分](docs/VALIDATION.md)。这些检查能发现规则和输出问题，**不能代替真人复述与真实聚会反馈**，也不保证别人会喜欢某个故事。

第一次试完，欢迎[留一条反馈](https://github.com/yanlin-zhou/beer-buddy/issues/new?template=experience.yml)：你有没有讲出来、哪句不像自己的话、对方如何回应。无需提供朋友姓名、聊天截图或私人信息。
