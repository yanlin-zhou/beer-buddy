# 啤酒搭子 🍻

**让这一口有个值得留意的地方。想聊天，也有件能顺口讲的小事。**

不必先懂精酿。想认识这杯，就给一个简单的观察和一句大白话解释；想听故事，就讲一个有来历的小故事。看完放下手机，按自己的感觉喝、用自己的话聊。

> **你：** 这瓶是 Happy Hops IPA，介绍一下，让我知道喝哪里有意思，别像上课。
>
> **啤酒搭子：** 先闻一下，喝的时候比比闻着和入口的感觉。酒厂用果香来形容 Happy Hops；酒花能带来香，也能带来苦，闻着像水果不代表喝着甜。
>
> 依据：[Russian River 酒款介绍](https://www.russianriverbrewing.com/brew/happy-hops-ipa/) · [Sierra Nevada 的 IPA 说明](https://sierranevada.com/style/ipa)

你也可以说“我没闻到水果，就觉得苦”。它会接着你的真实感受说，不要求你找到介绍里的味道，也不劝你喝到喜欢。

## 现在就试

**[打开「先试这一杯」，复制给你的 AI →](START.md)**

不用安装，轻量版带一个品饮入口和 3 条有来源的故事。先发这段指令，再发酒名或自己的场景；对话工具能看图时，也可以拍酒标。它不是独立 App，需要你正在使用的 AI 对话工具。

想长期用，有两种完整入口：

- **普通 AI 对话：** [下载完整 PROMPT.md](https://github.com/yanlin-zhou/beer-buddy/releases/latest/download/PROMPT.md)，上传后说“请按文件中的啤酒搭子帮我”。也可[在线查看](PROMPT.md)。
- **使用 Skills 的用户：** [下载 v1.1.0 安装包](https://github.com/yanlin-zhou/beer-buddy/releases/download/v1.1.0/beer-buddy-1.1.0.zip)，按 [Claude / Codex 安装说明](docs/INSTALL.md)使用。

## 不知道说什么，就这样开口

| 此刻 | 复制这一句 |
| --- | --- |
| 酒来了，想知道喝哪里 | 这是 Happy Hops IPA，给我一个现在能留意的小特点，别背品鉴词。 |
| 喝普通拉格 | 我平时只觉得冰爽，这杯还能留意什么？简单说。 |
| 烧烤摊喝青岛 | 大家喝青岛，来点能聊的地方小事，别把我们往精酿带。 |
| 只想听故事 | 这是福佳白啤，给我一个不用懂酒也听得明白的故事，不要品酒教程。 |
| 朋友问怎么样 | 我只觉得苦，帮我说一句，别替我编别的味道。 |
| 不喝酒也一起坐着 | 有人不喝酒，找个大家都能参与的话题。 |
| 对方聊起音乐 | 她更喜欢这家店的音乐，帮我自然接一句。 |
| 赶着点单 | 我平时喝百威，只在皮尔森和双倍 IPA 里选一个，快一点。 |
| 今天结束了 | 帮我记录：今天喝的这款我觉得苦。不要再推荐下一杯。 |

可以随时说“太长了”“换个路数”“这不像我平时说话”。对方没接，不必用更厉害的知识补救；停一下也可以。

## 里面有什么

**知道这一口可以留意什么。** 按酒款或风格挑一个入口：闻着与喝着的差别、嘴里的气泡、厚薄，或喝后留下什么。每次只选一个，不安排整套看、闻、喝。酒厂描述是线索，你的感受由你来说。

**13 条带来源的故事与趣闻。** 有拎着回家的青岛散啤、杯垫上的账单、送奶工重新酿起的白啤，也有 Happy Hops 酒标上回来的老角色。故事、观察和传说分别标注，品牌自述会保留“酒厂讲过”的说法。怕记不住时，再让它给三个词，不用背原句。

还有选酒、看标签、采购容量、回应朋友和记录的参考资料。支持文字；宿主能读图时，也可以发酒单或酒标。看不清就承认，不凭酒的颜色猜度数，更不会替你说“我闻到了什么”。只要故事就只讲故事，只问怎么倒酒就先解决倒酒。

专业资料以啤酒为主。在葡萄酒、白酒等聚会里也能帮你接话，但目前没有这些酒类的专业故事库。不会为了聊天要求任何人喝酒。

## 我们怎么判断它好不好

三个问题：**看完是否知道可以留意什么？能否放下手机，用自己的话讲？身边的人是否愿意接着聊？** 没找到新感觉、仍然不喜欢、对方没接话，都可以如实记录。

v1.1 来自一位用户试用后的反馈，以及多 Agent 从产品、心理、品饮、写作和社交表达等角度的研究与审查。[为什么这样改](docs/V1.1_RESEARCH.md) · [验证记录及尚未验证的部分](docs/VALIDATION.md)。Agent 检查能发现规则和输出问题，**不能代替真人品饮、复述与真实聚会反馈**，也不保证介绍会让酒变得更好喝。

第一次试完，欢迎[留一条反馈](https://github.com/yanlin-zhou/beer-buddy/issues/new?template=experience.yml)：有没有多留意到一点、是否像在找标准答案、哪句不像自己的话、对方如何回应。无需提供朋友姓名、聊天截图或私人信息。
